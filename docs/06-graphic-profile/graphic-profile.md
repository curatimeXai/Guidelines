# 🖼️ Graphic Profile

**Machine Learning Thrive Project** applies the same custom color chart as the graphic profile of _Johannes Gutenberg University_ to showcase that the project is connected to the university.

<br>

## 🔤 Font

`font-family: Noto Sans, serif;`

Noto Sans is chosen to follow the university's profile.

This section outlines the project's color palette, including brand colors and utility/UI-specific colors. All colors are defined using oklch for perceptual uniformity and are mapped to custom CSS variables in the Tailwind config for easy reuse.
