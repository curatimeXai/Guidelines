# Submitting Work Items

---

## Reporting a Bug
**1.** Open the repository, select Issues, and click New Issue -> Bug Report.  
  
**2.** Title: `[BUG]: <Clear, concise description>`  
(e.g., `[BUG]: Dark mode toggle does not persist after page refresh`)  
  
**3.** Required Fields:
   - Summary
   - Component
   - Steps to Reproduce
   - Expected Result
   - Actual Result
   - Severity
   - Priority.
  
**4.** Issue Type: Set to Bug to activate pinned classification fields (severity).

---

## Creating a Task or Feature Request
**1.** Open the repository, select Issues, and click New Issue -> Feature / Task (or Blank Issue).
   
**2.** Title: [FEATURE]: <Short summary> or [TASK]: <Short summary>
   
**3.** Required Specifications:
   - Context / Value: High-level summary of the requirement and its objective.
   - Acceptance Criteria (AC): Concrete, measurable conditions required for sign-off.
   - Technical Details (Optional): Impacted endpoints, schema migrations, or external libraries.
